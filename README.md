# 실습 시간 계산기

실습 강의용 시간 배분 웹앱. 서버 없이 정적 페이지(GitHub Pages)로 동작하며, 진행 상황은 브라우저 localStorage에만 저장됩니다.

## 사용 방법

1. 실습 목록이 담긴 엑셀 파일(.xlsx)을 업로드합니다.
   - A열: 실습명
   - B열: 계획 시간(분)
   - (선택) `구분` 열에 `시작시간` 행을 두고 C열에 시작 시각을 넣으면 시작 시각이 자동으로 채워집니다.
2. 수업 시작 예정 시각, 목표 종료 시각(예: 17:10), 참고용 강의 최종 종료 시각(예: 17:30)을 확인/수정합니다.
3. "수업 시작"을 누르면 타이머가 시작됩니다.
4. 각 실습을 마칠 때마다 해당 행의 "완료" 버튼을 누릅니다. 실제 소요 시간이 분 단위로 기록되고, 아래에 남아있는 실습들의 추천 소요 시간이 목표 종료 시각에 맞춰 비율대로 자동 재조정됩니다.
   - 예정보다 늦어지면 남은 실습들의 추천 시간이 비율만큼 줄어듭니다.
   - 예정보다 빨리 끝내면 남은 실습들의 추천 시간이 비율만큼 늘어납니다.
   - 목표 종료 시각을 이미 넘겼다면 경고 배너가 뜨고 남은 실습은 최소 시간으로 표시됩니다.
5. 모든 실습을 마치면 요약 화면에서 계획 대비 실제 소요 시간을 확인할 수 있습니다.

## 기술 스택

순수 HTML/CSS/JavaScript(바닐라)로만 작성했고, 엑셀 파싱에 [SheetJS(xlsx)](https://sheetjs.com/)를 CDN으로 불러와 사용합니다. 빌드 과정이 없어 저장소를 그대로 GitHub Pages로 배포하면 바로 동작합니다.

## 로컬에서 미리보기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
