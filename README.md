# 실습 시간 계산기

실습 강의용 시간 배분 웹앱. 엑셀 업로드 없이 앱 안에서 표(행/열)를 직접 입력하며, 서버 없이 정적 페이지(GitHub Pages)로 동작합니다. 진행 상황은 브라우저 localStorage에만 저장됩니다.

## 사용 방법

1. 실습명과 기준 시간(분)을 표에 직접 입력합니다. "+ 실습 추가"로 행을 늘리고, ×로 행을 지울 수 있습니다.
2. 시작 시각, 목표 종료 시각(예: 17:10), 참고용 강의 최종 종료 시각(예: 17:30)을 입력합니다. "지금" 버튼을 누르면 시작 시각이 현재 시각으로 바로 채워집니다.
3. 값을 바꿀 때마다 각 행의 추천 시작~종료 시각이 목표 종료 시각에 맞춰 즉시 자동 재계산됩니다(기준 시간 비율대로 배분).
4. "수업 시작"을 누르면 그 순간의 시각이 시작 시각으로 기록되고 진행이 시작됩니다.
5. 각 실습을 마칠 때마다 해당 행의 "완료" 버튼을 누릅니다. 실제 소요 시간이 분 단위로 기록되고, 남아있는 실습들의 추천 시간이 목표 종료 시각에 맞춰 비율대로 자동 재조정됩니다.
   - 예정보다 늦어지면 남은 실습들의 추천 시간이 비율만큼 줄어듭니다.
   - 예정보다 빨리 끝내면 남은 실습들의 추천 시간이 비율만큼 늘어납니다.
   - 목표 종료 시각을 이미 넘겼다면 경고 배너가 뜨고 남은 실습은 최소 시간으로 표시됩니다.
   - 진행 중에도 남은 실습의 실습명·기준 시간을 바로 수정하거나 행을 추가/삭제할 수 있고, 상단 "설정"에서 목표/시작 시각도 바꿀 수 있습니다. 바꿀 때마다 자동으로 다시 계산됩니다.
6. 모든 실습을 마치면 요약 화면에서 계획 대비 실제 소요 시간을 확인할 수 있습니다.

## 기술 스택

순수 HTML/CSS/JavaScript(바닐라)로만 작성했으며 외부 라이브러리나 빌드 과정이 없습니다. 저장소를 그대로 GitHub Pages로 배포하면 바로 동작합니다.

## 로컬에서 미리보기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
